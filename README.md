# For training practice

## Описание
Учебный проект для отработки навыков Git Flow в рамках ПМ.02 
«Осуществление интеграции программных модулей».
## Программный модуль «Автопарк»

Автоматизация учёта автомобилей, водителей, расхода топлива, технического обслуживания и формирования отчётности.

## Содержимое репозитория

| Файл | Описание |
|------|----------|
| `Техническое задание.docx` | Требования к модулю по ГОСТ 19.201-78 |
| `Анализ предметной области.docx` | Сущности, бизнес-правила, роли пользователей |
| `Автопарк.mdj` | UML-диаграммы (StarUML) |
| `Спецификация Class_Diagram.docx` | Детальное описание диаграммы классов |
| `Спецификация USE_Case_Diagram.docx` | Описание вариантов использования |
| `Avtopark_AS-IS.rsf` | Диаграмма бизнес-процессов «как есть» |
| `Avtopark_TO-BE.rsf` | Диаграмма бизнес-процессов «как будет» |
| `.gitignore` | Исключаемые файлы |
| `README.md` | Описание проекта |

## Инструкция по работе

1. Клонировать репозиторий
2. Открыть файлы в соответствующих программах:
   - `.docx` — Microsoft Word
   - `.mdj` — StarUML
   - `.rsf` — Ramus Educational
